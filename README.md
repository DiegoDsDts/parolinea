# Parolinea

Parolinea e un gioco di parole per browser ispirato al classico Boggle. Questa versione e stata ricostruita in Svelte con input touch, mouse e penna, layout responsive e calcolo delle soluzioni in Web Worker.

## Sviluppo

```bash
npm install
npm run dev
```

## Comandi

```bash
npm run check
npm run build
npm run preview
```

## Funzioni principali

- griglie configurabili da 3x3 a 8x8
- durata illimitata o a tempo
- lunghezza minima delle parole configurabile
- generazione casuale pesata sulle lettere italiane
- griglia manuale e import sfida tramite link compatto
- riepilogo con parole trovate, soluzioni totali e punteggio
- tema chiaro, scuro o di sistema
